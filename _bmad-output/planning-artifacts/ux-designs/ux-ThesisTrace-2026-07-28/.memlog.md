- (assumption) D7 only excludes TradingView-style off-the-shelf ticker/candlestick widgets, not charting libraries generally — D7 explicitly names Recharts/visx as acceptable for custom charts over ThesisTrace's own computed data (Piotroski subscores, Altman components, accrual trends, provenance-tagged lines). DESIGN.md/EXPERIENCE.md should treat a lightweight charting library as in-scope for sparklines/trend/gauge components, not require hand-rolled SVG-only.
- (decision) Mode: Fast path. Lawrence explicitly delegated the creative direction ('figure this out on your own... come up with the best design possible') rather than wanting a long elicitation walkthrough. Non-obvious judgment calls are tagged [ASSUMPTION] in the spines instead of being asked as questions.
- (event) Current-state audit performed directly (not delegated): seeded local dev DB from the real committed golden-dataset fixtures (QSR/CP/OTEX hand-verified, SHOP still placeholder per HANDOFF.md), ran backend+frontend locally, took real Playwright screenshots of landing/company/compare/methodology pages, read every frontend source file (globals.css tokens, layout.tsx, all page.tsx, all app/components/ui/*.tsx) and the API schemas. Findings: clean, thoughtfully-tokenized (tri-state signal palette is a real strength) but visually thin 'SaaS-MVP' look — single centered column max-w-5xl (1024px), no dark mode, no defined type scale beyond Tailwind defaults, only one visualization primitive anywhere (a 6px-tall linear band gauge with a dot marker), no historical/trend charts, no command palette, minimal single-link top nav, generic Inter font with no distinctive display/brand typography moment.
- (assumption) [ASSUMPTION] Audience calibration: PRD non-users list explicitly excludes day traders/technical analysts ('no candlestick tools, no technical indicators, no TradingView-style widgets') and the primary JTBD is evidence-based long-term equity research, not trading. 'Enterprise-grade' here should read as institutional equity-research terminal (Bloomberg Research/FactSet/Morningstar Direct register) rather than a trading-platform register (TradingView/Robinhood) — sober, credible, citation-forward, not gamified or trade-action-oriented.
- (assumption) [ASSUMPTION] Provenance should become visually first-class, not an afterthought. AD-19 states the read API returns provenance and 'the frontend links to it' — current implementation only renders provenance as plain small gray text (concept + fiscal year), not an actual link. Recommend rendering provenance as a real link out to the SEC EDGAR filing (constructible client-side from CIK + accession_number, no backend change needed) or, at minimum, a much more prominent citation chip — this is the product's core differentiator per PRD UJ-1/UJ-2 and should look like it.
- (assumption) [ASSUMPTION] Historical/trend visualization (e.g. a Piotroski/Altman sparkline across fiscal years) is a strong candidate for the 'enterprise' upgrade and the DB already stores multiple fiscal years per company, but the read API (/api/companies/{ticker}/overview) currently returns only the single current-run fiscal year — any trend-chart recommendation in this spec should be flagged as requiring a new/extended backend endpoint, not purely a frontend change.
- (decision) Drafted DESIGN.md's Layout & Spacing, Elevation & Depth, and Shapes sections plus a spacing/rounded token scale ahead of the research landing, since those are largely independent of the Bloomberg/Koyfin/etc. competitive-color/typography findings. Brand & Style, Colors, Typography, and Components sections deliberately left as explicit PENDING RESEARCH SYNTHESIS placeholders rather than guessed, per the instruction to base the visual direction on real research, not assertion.
- (event) Competitive design-research pass completed (Bloomberg Terminal, Koyfin, Simply Wall St, TipRanks, Finchat.io, Morningstar, YCharts, stockanalysis.com) via web research subagent.
- (decision) Register: Morningstar + stockanalysis.com (+ YCharts) as closest visual analogs — achromatic/disciplined rating display, single restrained accent, chrome-free dense tables. Explicitly rejected: Simply Wall St/TipRanks' single colorful 'hero visualization' pattern, and Bloomberg/Koyfin's amber-terminal/command-key trading-desk aesthetic.
- (decision) Colors: kept existing tri-state signal palette + single brand blue as-is (no companion accent). Added a dark-mode core token set ([ASSUMPTION], justified by Koyfin/Simply Wall St both offering dark mode) with dark badge bg/border derived at implementation time via reduced-opacity color-mix, not hand-picked — flagged for a contrast audit before shipping.
- (decision) Typography: kept Inter (no companion display/serif face) and the existing system-monospace stack, widened the mono role from score-values-only to every tabular numeric context (comparison table, methodology inputs, provenance text) per stockanalysis.com's dense-table pattern. Added a named type scale (display/headline/title/body/label/caption/data) replacing ad hoc Tailwind utility sizes.
- (decision) Gauge redesign: tick-marked horizontal band (zone boundaries drawn, marker filled by signal color), explicitly not a radial/circular dial — the radial-dial pattern (Snowflake, Smart Score) was identified as the consumer-fintech 'hero visualization' anti-pattern to avoid. Also spec'd new citation-chip (outlined, transparent, mono fiscal-year/accession text, real <a> to EDGAR) and sparkline components (sparkline depends on an unshipped backend endpoint extension, deferred to Phase-next).
- (decision) Key-screen visual mocks were not rendered in this pass (Fast path — spec text/tokens prioritized to close the pending-research blocker). Reviewer Gate (rubric walker / validation lenses) also not run — no user available mid-session to pick lenses; offered as a follow-up rather than skipped silently.
